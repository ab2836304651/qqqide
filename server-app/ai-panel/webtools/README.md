# webtools — 受控浏览器工具链（AI 操作网页的标配）

qd 自带内核即浏览器：**零外部依赖**（无需 Chrome/Edge、无需装任何驱动），新电脑、
Win7、干净系统全可用。本目录 = 「受控浏览器」的用法协议 + 现成驱动代码。

```
webtools/
├── README.md        ← 本文件：AI 面向的作业协议（先读这个）
└── kit/
    ├── qdbrowser.py  # 受控浏览器：确保就绪 / 查询 / 停止（核心；内核自动定位）
    ├── cdp.py        # 最小 CDP 客户端（自动发现端口；Tab 操作全靠它）
    ├── fill.py       # 三档填框（React 吃字治理）
    ├── pin.py        # 剪贴板注入（富文本粘贴；Windows/macOS/Linux 全平台）
    ├── probe.py      # 页面探针（到新站第一步）
    ├── demo.py       # 30 秒验通
    ├── selftest.py   # 端到端自检（可见/隐藏/二次实例/空闲自退/exit-with）
    └── cdp_launch.py # 外部浏览器兜底（极少数强风控站点用）
```

## 快速开始（三步）

```bash
# ① 确保受控浏览器就绪（没有就起，有就复用）——打印端点 JSON（含 cdpPort）
python kit/qdbrowser.py ensure

# ② 验通链路（连上 → 导航 → 读回 → 截图）
python kit/demo.py

# ③（推荐）整机自检：可见/隐藏/二次实例/空闲自退/exit-with 一把过（约 4 分钟）
python kit/selftest.py
```

依赖（仅两个，标准环境一次装好）：`pip install requests websocket-client`
（缺依赖时 pip 装到当前解释器即可；在 qd 里运行会自动用内置 Python。）

系统小工具（可选增强，缺失只降级不报错）：
- **Linux**：`xclip`/`wl-copy`（富文本剪贴板）、`xdotool`（最小化窗口自动恢复）、`xprop`（窗口状态检测）。
- **macOS / Windows**：剪贴板与窗口恢复均用系统自带能力，无需额外安装。

## 受控浏览器域（它是什么）

- **单例**：全局只有一个受控浏览器；任务=页面，不再是"一个任务一叠窗"。
- **窗口**：默认可见（人可监工；AI 干活、人看效果）。批处理用 `ensure --hidden` 开静默档。
- **登录态持久**：profile 存在 qd 数据目录（`{Data}/browser-host/`），扫码登录一次长期免登。
- **CDP 端口**：8335 段自动选空闲口；端点写入报告文件 + 权威心跳 `host.json`——`cdp.py`
  自动读取，**不需要你记端口**；两个 kit 各自 TEMP 不同也能互见同一实例。
- **退出**：关掉浏览器窗口即退出（登录态保留）；或 `python kit/qdbrowser.py stop`。
- **换机器**：什么都不用配——qd 装在哪，浏览器就在哪（内核路径由工具包自身位置自动推导，
  Windows/macOS/Linux 三平台一致；多装包并存用 `--shell` 或环境变量 `QQQIDE_SHELL` 指定）。

### 静默档（--hidden）的语义

- **hidden 是实例级属性**：隐藏档实例**不会被任何二次请求弹出/抢焦点**（防批量任务中途冒窗），
  其 `window.open` 子窗也继承隐藏。
- **需要用户看时**（扫码/验证码）：先 `stop` 再 `ensure`（可见）——登录态在 profile 里，不丢。
- **空闲自退**：隐藏档默认 **30 分钟**无 CDP 客户端连接且无页面活动 → 自行退出（防隐形孤儿进程
  常驻）。覆盖：`ensure --hidden --idle-exit 120`（分钟；`0` = 关闭——长跑批处理建议设大值或关）。
  可见档默认不自动退出。
- **任务跟随**（可选）：`ensure --exit-with <pid>`——监督进程退出时浏览器跟着退出（防孤儿）。
  以上三个开关都只在**新起实例**时生效。

### ensure --url 语义

- 新起实例：窗口直接加载该网址。
- 复用现有实例：派发一次导航（**不开新窗**）；可见实例会带到前台，隐藏实例静默导航。

## cdp.py 速查

| 调用 | 作用 |
|---|---|
| `cdp.tab_for_url("baike.baidu.com")` | 按 URL 子串定位页（**永远这样定位，绝不按序号**） |
| `cdp.first_page()` | 取第一个页（兜底） |
| `cdp.Tab(t["webSocketDebuggerUrl"])` | 连接该页 |
| `tab.goto(url, wait=3)` | 导航 |
| `tab.js("document.title")` | 执行 JS 并取回值 |
| `tab.insert_text("文字")` | **可信打字**（insertText——React 也认；先聚焦目标元素） |
| `tab.click_xy(x, y)` / `tab.hover_xy(x, y)` | 真鼠标（坐标先 `tab.clamp(x, y)` 钳进视口） |
| `tab.press_key("Enter", vk=13, code="Enter")` | 按键 |
| `tab.shot("x.png")` | 截图（窗口被遮挡/失焦照样出图；最小化自动无焦点恢复；隐藏档自动唤醒帧） |
| `tab.viewport()` | 取视口尺寸 |

## 铁律（违反=白干，血泪版）

1. **先探再动**：到新站先 `probe.py`，别按猜测写选择器。
2. **写后必验**："没报错" ≠ "成功"——填框读回值、上传数产物、点确定查弹窗+扫报错词。
3. **坐标必钳制**：真鼠标坐标超出视口会**静默落空**（`tab.clamp`）。
4. **打字用 `insert_text`**；直接 `js("el.value=...")` 会被 React 吃字（要写值就用三档填框 `fill.py`）。
5. **抓取竞态**：页面自动抓取/校验会**清空你刚填的字段**——等状态尘埃落定再确认；确认前复检关键字段。
6. **同名控件先 dump 再选**；一切元素先过滤"可见"（`offsetHeight>0 && rect.width>0`）。
7. **hover 才挂载的菜单**：先 `hover_xy` 等出现，再对菜单项用 JS `click()` 或量坐标点击。
8. **登录/验证码/人脸 = 唯一叫人项**：停下来把窗口留给用户操作，完成后再继续。不硬闯风控。
9. **花钱/不可逆动作**（提交/发布/付款/删除）：停下等用户一句确认（除非已明确预授权）。
10. 每个关键动作前一句话说明"我在干什么"（用户屏幕是直播状态）。

## 外部浏览器兜底（少数场景）

个别站点强依赖更新的浏览器内核时，可改用外部调试浏览器（先装好 Chrome/Edge）：

```bash
python kit/cdp_launch.py            # 起外部浏览器（专用 profile）
# 之后脚本经环境变量指向它：set CDP_PORT=63788
```

`cdp.py` 的端口解析顺序：`CDP_PORT` 环境变量 > 受控浏览器（报告文件 → 权威 host.json）> 传统默认口
——**默认走受控浏览器**。

## 平台与实态（实话）

| 平台 | 受控浏览器 | 说明 |
|---|---|---|
| Windows | ✅ 真机全量实测 | 起/停/复用/导航/打字/截图/隐藏档唤醒/二次实例/空闲自退/exit-with 全绿 |
| macOS | ✅ 真机全量实测 | 同上全绿（macOS 12 x64）；窗口结构性不可最小化；富文本剪贴板走 AppleScript「HTML」格式 |
| Linux | ✅ 真机全量实测 | 同上全绿（Ubuntu 24.04 · Wayland/XWayland）；最小化窗口截图前自动恢复（xdotool windowactivate；无 xdotool 时明确报错）；富文本剪贴板走 xclip/wl-copy |

其余边界：

- 受控浏览器内核 = qd 壳层内核（版本随 qd 发布走）；主流站点全兼容，个别强风控站点用外部兜底。
- 下载文件自动落 `{Data}/browser-host/Downloads/`（重名 `name_1.ext`），不落 C 盘；
  启动后台浅清：30 天龄直清 + 总量 2GB 硬线按最老优先清到 1.5GB（不碰 24 小时内的新文件）。
- 受控浏览器开可见窗期间，qd 的自动更新会等窗口关闭后再换装（正常现象）；隐藏档无可见窗，不推迟。
- 该窗口**设计上不可最小化**（最小化会暂停渲染 → 截图等待）：Windows/Linux 里系统级手段仍可能
  把它收起来——截图前会自动恢复（Windows 无焦点恢复；Linux 需 `xdotool`，无则截图会明确报错
  「渲染帧停产」）；macOS 里这条路径结构性不可达（窗口没有最小化能力）。想收起来请直接关闭窗口——
  下次任务自动重开，登录态保留。被别家窗口遮挡不影响截图（本窗帧供给不因遮挡中断）。
- 旧版 qd 的包里没有这套能力时，`qdbrowser.py` 会**明确报错**（不会误启动老包）。
